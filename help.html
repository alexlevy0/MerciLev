🔧 Configuration en service (optionnel)

Pour démarrer Ollama automatiquement :

sudo tee /etc/systemd/system/ollama.service > /dev/null << EOF [Unit] Description=Ollama Service After=network.target [Service] Type=simple Environment="OLLAMA_ORIGINS=*" ExecStart=/usr/local/bin/ollama serve Restart=always User=$USER [Install] WantedBy=multi-user.target EOF sudo systemctl enable ollama sudo systemctl start ollama

🔧 Dépannage

❌ Erreur "Access forbidden (403)"

Assurez-vous de lancer Ollama avec OLLAMA_ORIGINS="*"

Windows : $env:OLLAMA_ORIGINS="*" avant ollama serve

macOS/Linux : OLLAMA_ORIGINS="*" ollama serve

❌ "Connexion refusée"

Vérifiez qu'Ollama est bien lancé avec ollama serve

Le serveur doit écouter sur http://localhost:11434

❌ Modèle non trouvé

Installez le modèle avec : ollama pull gemma3n:e2b

Vérifiez les modèles installés : ollama list
